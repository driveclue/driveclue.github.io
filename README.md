# DriveClue website

Static website for [DriveClue](https://github.com/driveclue/DriveClue), published with GitHub Pages at [driveclue.github.io](https://driveclue.github.io/).

The site uses plain HTML and CSS. To preview it locally, run `python3 -m http.server 8000` in this directory and open `http://localhost:8000/`.
